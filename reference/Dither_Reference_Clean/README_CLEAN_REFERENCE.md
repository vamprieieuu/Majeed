# Dither Reference - Clean Package

This package is a cleaned reference set for rebuilding a Dither effect.

Use it only as a technical/reference source:
- inspect algorithms, patterns, controls, parameters, and visual behavior
- reimplement the behavior in the MAJEED native C++ engine
- do not reuse licensing, activation, bypass, installer, or old-plugin packaging code
- do not treat reference images as textures unless explicitly required for visual comparison
- do not preserve old product/company branding

The package has had unrelated licensing/installation/plugin-manifest infrastructure removed,
and obvious old product/vendor identifiers in text metadata have been neutralized.

Important: cleaning names/metadata does NOT establish ownership or change any third-party
license terms that may apply to source code or libraries. Preserve required open-source
license notices where they are technically necessary.
