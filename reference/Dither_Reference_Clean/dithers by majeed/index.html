Mask Mode: When toggled, dithers only the layer mask of the target layer..
Save Settings: Saves your chosen dither settings for next time.
Batch Render: When toggled, will apply the chosen dither effect across all layers in your document. Best used when working in a layer frame animation. Please watch this video before using.
Knockout Mode: When toggled, knocks the background color out of your dithered layer upon render.
Import Palette: Source the color palette from any image by pasting the image on the canvas, then clicking this button. Watch how it works here.
Color Picker: Use this button to fine-tune your palette - click any color on the canvas to change it in real-time.
Reset Palette: Clicking this button will reset your color palette to its default state.
Palette Swatch Modifiers: Click a swatch to recolor it. Alt+click to suppress a color from output (pixels reroute to the nearest active color). Shift+click then Cmd/Ctrl+click to merge near-duplicate colors. Manual edits survive slider adjustments.
Grain / Fade Mode: Toggle between Grain Mode for a stippled, diffused look (maximum of 8 colors), or Fade Mode for a posterized, fuller look (maximum of 64 colors).
